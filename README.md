# BN Tech Bot

Python Telegram bot using Supabase.

## Setup

1. Install Python 3.11 or a compatible version.
2. Install dependencies:

   pip install -r requirements.txt

3. Configure required credentials as environment variables in your hosting
   provider. Never commit real tokens, passwords, or service-role keys.

4. Start the bot using the command required by your project:

   python bot.py

Check the existing bot code for its required environment variable names
before deploying.
